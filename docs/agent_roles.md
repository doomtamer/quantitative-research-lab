# Zespół agentów — nadzorowany

**Human Research Lead (Ty):** zatwierdza hipotezy, targety, metodologię, źródła płatne i wnioski.

- **Research Director:** rozdziela zadania i pilnuje procesu.
- **Data Engineer:** źródła, jakość, timestampy, wersjonowanie.
- **Quant Researcher:** hipotezy, testy, benchmarki, statystyka.
- **Crypto Researcher:** mechanika funding rate, OI, pozycjonowania.
- **Quant Developer:** implementacja zatwierdzonego kodu i testy.
- **Research Auditor:** niezależny audyt leakage, bias, stabilności i replikacji.

Przepływ: plan → zatwierdzenie człowieka → implementacja → audyt → zatwierdzenie raportu. Agent nie może samodzielnie audytować i zatwierdzać własnego wyniku. Nie uruchamiamy automatycznego handlu.
